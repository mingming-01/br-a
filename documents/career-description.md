## 1. 아이티윌 백엔드 개발 교육

**기간:** 2024.08 ~ 2025.05  
**구분:** 개발 교육 및 팀 프로젝트

### 경험 내용

웹 백엔드 개발을 중심으로 Java와 JavaScript 등을 학습하고 여러 팀 프로젝트를 진행했습니다.

기능을 구현하는 것뿐 아니라 여러 사람이 작업한 내용을 하나의 서비스로 연결하는 과정을 경험했습니다. 문제가 발생하면 먼저 원인을 확인하고 필요한 내용을 찾아보며 해결했고, 혼자 해결하기 어려운 부분은 팀원에게 질문하며 작업을 진행했습니다.

### 주요 경험

- Java 및 JavaScript 기반 웹 개발 학습
- 백엔드 개발 및 웹서비스 구현
- 팀 단위 프로젝트 수행
- 기능 구현 및 서비스 연결
- 오류 원인 확인 및 문제 해결
- 팀원과의 작업 조율 및 협업

## 2. Stock Mate

**구분:** 아이티윌 팀 프로젝트

### 프로젝트 개요

QR/바코드를 활용해 상품과 재고를 관리할 수 있도록 만든 웹서비스입니다.

### 주요 구현 경험

- 로그인 기능
- QR/바코드를 활용한 상품 관리
- 재고 조회 및 관리
- 팀원과 역할을 나누어 기능 개발
- 교육기관 제공 서버를 이용한 서비스 배포

### 경험 및 배운 점

하나의 기능을 독립적으로 구현하는 것과 실제 서비스 안에서 다른 기능과 연결하는 것은 다르다는 것을 경험했습니다. 팀원의 작업 내용을 이해하고 서로 맞춰 가면서 하나의 서비스를 완성하는 과정을 배웠습니다.

*현재는 교육기관 제공 서버 운영 종료로 서비스 접속이 어렵습니다.*

**GitHub:** github.com/in27sung/stock-mate

## 5. Maple Growth Tracker

**구분:** 개인 프로젝트  
**형태:** 웹서비스  
**배포:** Render

### 프로젝트 개요

메이플스토리 캐릭터의 성장 기록을 확인하기 위해 만든 개인 웹서비스입니다.

공개 API에서 캐릭터 데이터를 가져와 필요한 정보를 가공하고, 성장 추이를 확인할 수 있도록 구성했습니다.

### 주요 구현 경험

- 공개 API를 이용한 캐릭터 데이터 조회
- API 데이터 가공 및 화면 표시
- 성장 기록 및 최근 성장 추이 확인
- 성장 속도 및 레벨업 예측
- Gemini API를 활용한 성장 데이터 분석
- 웹서비스 구현 및 배포

### 결과 및 경험

관심 있는 주제에서 필요한 기능을 직접 정하고 서비스를 구현했습니다. 개발 환경에서 실행되는 결과물에 그치지 않고 실제로 사용할 수 있는 형태까지 만들고 배포하면서 아이디어를 서비스로 연결하는 경험을 쌓았습니다.

**Service:** maple-growth-tracker.onrender.com  
**GitHub:** github.com/mingming-01/maple-growth-tracker

## 8. 시각적 효과가 타이핑 성능에 미치는 영향

**구분:** SKT K-뉴딜 ALEPH 과제 10 · 연구 프로젝트  
**기간:** 2026

### 프로젝트 개요

타이핑 화면의 시각적 효과가 사용자의 타이핑 성능에 영향을 주는지 확인하기 위해 직접 실험하고 데이터를 분석했습니다.

### 주요 수행 내용

- 타이핑 실험 페이지 제작
- 실험 조건 설계
- 실험 데이터 수집
- CSV 데이터 정리
- Python을 활용한 데이터 분석
- 조건별 타이핑 속도 및 정확도 비교
- 분석 결과 시각화
- 연구 결과를 논문 형태로 정리
- 재현 가능한 분석 구조 구성

### 결과 및 경험

처음에는 시각적 효과가 타이핑 성능을 떨어뜨릴 것이라고 예상했습니다. 그러나 실제 데이터를 분석한 결과 예상과 완전히 일치하지 않았습니다.

가설에 결과를 맞추기보다 실제 데이터를 기준으로 결론을 정리하면서, 예상한 답보다 직접 확인한 결과를 바탕으로 판단하는 것이 중요하다는 것을 경험했습니다.

**Project:** mingming-01.github.io/typing-focus-research/

### 주요 경험

- AI를 활용한 개발 및 문제 해결
- 요구사항 확인 및 작업 계획

- 데이터 수집 및 분석

- 프로젝트 문서화
- 재현 가능한 결과물 구성
- 다양한 개인 과제 및 실습 수행

- **Card Studio** — 카드 및 콘텐츠 제작 서비스
- **과제 10** — 타이핑 실험 및 데이터 분석

모든 결과물을 동일한 비중의 프로젝트로 구분하기보다, 교육 과정에서 수행한 다양한 과제와 실습 경험으로 정리하고 대표 결과물은 별도로 관리했습니다.

## 10. 종합 역량

### 문제 해결

문제가 발생했을 때 바로 수정하기보다 현재 상태와 원인을 먼저 확인합니다. 필요한 정보를 직접 찾아보고 해결 방법을 적용한 뒤 실제로 문제가 해결되었는지 다시 확인합니다.

### 구현 및 결과물 완성

아이디어나 요구사항을 기능으로 구체화하고 실제 실행 가능한 결과물까지 만드는 경험을 쌓았습니다. 개인 프로젝트에서는 웹서비스를 직접 구현하고 배포했으며, 연구 프로젝트에서는 실험부터 데이터 분석과 논문 작성까지 진행했습니다.

### 데이터 기반 판단

처음 세운 가설이나 예상에 결과를 맞추기보다 실제 데이터를 확인하고 그 결과를 기준으로 판단하려고 합니다. T10 연구에서 예상과 다른 결과를 직접 확인하고 이를 바탕으로 결론을 정리한 경험이 있습니다.

### 협업

팀 프로젝트에서 담당 기능을 구현하고 다른 팀원의 작업과 연결하는 경험을 했습니다. 특히 담당 작업을 완료한 뒤 다른 팀원의 작업을 지원하면서 팀 전체의 결과물을 완성하는 과정에도 참여했습니다.

### 자기주도적 학습

모르는 내용이 생기면 먼저 필요한 정보를 찾아보고 직접 적용해 봅니다. 단순히 학습 내용을 이해하는 데 그치지 않고 실제 프로젝트나 결과물에 적용하면서 익히는 방식을 선호합니다.

## 11. 지원 직무

소프트웨어 개발을 중심으로 경험을 쌓고 있으며 다음과 같은 직무에 관심을 가지고 있습니다.

- 백엔드 개발
- 웹서비스 개발
- MES / ERP 등 업무 시스템 개발
- 제조·반도체 분야와 소프트웨어를 연결하는 개발 업무
- 데이터와 소프트웨어를 활용한 문제 해결 업무

나노융합공학을 전공하며 반도체와 제조 분야를 경험했고, 이후 백엔드 개발 교육과 다양한 소프트웨어 프로젝트를 경험했습니다.

앞으로는 두 경험을 따로 생각하기보다 소프트웨어를 통해 현장의 문제를 해결하는 방향으로 연결하고 싶습니다. 새로운 업무를 맡았을 때 필요한 내용을 직접 배우고 확인하면서, 실제로 사용할 수 있는 결과물을 만드는 개발자로 성장하고자 합니다.
