# 자기소개서

## 모르는 것을 확인하고, 필요한 결과까지 만들어 가는 사람입니다

저는 새로운 일을 맡았을 때 처음부터 모든 것을 알고 시작하기보다, 현재 상황을 확인하고 필요한 것을 하나씩 찾아가는 방식으로 문제를 해결합니다. 모르는 부분이 생기면 먼저 자료를 찾아보고 직접 실행해 봅니다. 혼자 해결하기 어려운 문제는 질문하고, 다른 방법이 더 적절하다면 기존에 생각했던 방식을 바꾸기도 합니다.

이런 방식은 개발을 배우면서 더욱 분명해졌습니다. 아이티윌에서 백엔드 개발을 공부하며 여러 팀 프로젝트를 진행했고, 하나의 기능을 구현하는 것만큼 다른 사람의 작업과 연결하는 과정이 중요하다는 것을 경험했습니다. 제가 맡은 작업을 끝내는 것에서 그치지 않고 다른 팀원의 작업을 도와 프로젝트를 진행하기도 했습니다. 이 과정에서 협업은 각자의 일을 나누는 것만이 아니라, 전체 결과물을 위해 서로의 상황을 이해하고 필요한 부분을 맞춰 가는 것이라는 것을 배웠습니다.

개인적으로 관심이 생긴 문제를 직접 서비스로 만들어 보는 것도 좋아합니다. Maple Growth Tracker에서는 공개 API의 데이터를 활용해 제가 확인하고 싶었던 정보를 웹서비스로 만들고 실제로 배포했습니다. 기능을 구현하는 과정에서 예상하지 못한 문제가 생기면 원인을 확인하고 하나씩 수정하면서, 아이디어를 실제로 사용할 수 있는 결과물까지 가져가는 경험을 했습니다.

SKT K-뉴딜 ALEPH 1기에서는 개발뿐 아니라 데이터와 결과를 직접 확인하는 경험도 쌓고 있습니다. 과제 10의 타이핑 연구에서는 시각적 효과가 성능을 떨어뜨릴 것이라는 가설을 세웠지만, 실제 데이터를 분석한 결과가 예상과 완전히 같지는 않았습니다. 처음 생각한 답에 결과를 맞추기보다 데이터를 기준으로 결론을 정리했습니다. 이 경험을 통해 문제를 해결할 때 중요한 것은 내가 처음에 생각한 답을 증명하는 것이 아니라, 확인한 결과를 바탕으로 다음 판단을 내리는 것이라는 것을 배웠습니다.

저의 강점은 특별한 지식을 많이 알고 있다는 것보다, 모르는 것을 그냥 넘기지 않고 필요한 것을 찾아 실제 행동으로 연결한다는 점에 있습니다. 동시에 혼자 해결하는 것만 고집하지 않고 다른 사람의 의견을 듣고 함께 해결할 방법을 찾으려고 합니다. 작업을 완료한 뒤에도 실제로 동작하는지 확인하고, 예상과 다른 부분이 있다면 다시 살펴보는 것도 중요하게 생각합니다.

저는 나노융합공학을 전공하면서 반도체와 제조 분야를 경험했고, 이후 백엔드 개발 교육과 여러 프로젝트를 통해 소프트웨어 경험을 쌓았습니다. 앞으로는 이 두 경험을 따로 생각하기보다 소프트웨어를 통해 현장의 문제를 해결하는 방향으로 연결해 보고 싶습니다. 특히 백엔드와 웹서비스 개발을 중심으로 경험을 쌓으면서 MES·ERP와 같은 업무 시스템이나 제조·반도체 분야의 소프트웨어 업무에도 관심을 가지고 있습니다.

아직 배워야 할 것이 많은 개발자이지만, 새로운 문제를 만났을 때 필요한 것을 배우고 직접 확인하며 끝까지 결과를 만들어 내는 태도는 계속 가져가고 싶습니다. 맡은 일을 단순히 완료하는 데 그치지 않고, 왜 필요한지 이해하고 실제로 사용할 수 있는 결과까지 연결하는 개발자로 성장하겠습니다.
