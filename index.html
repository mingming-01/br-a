MAPLE GROWTH TRACKERPERSONAL · 2026.09 —

현재 상태를 넘어 성장의 흐름을 기록하는 웹서비스

캐릭터 조회 API는 현재 시점의 정보가 중심이기 때문에, 시간이 지나며 얼마나 성장했는지 확인하려면 과거 기록을 직접 쌓아야 했습니다. 이 문제를 해결하기 위해 NEXON Open API 데이터를 날짜별로 저장하고, 성장 분석·캐릭터 비교·상세 조회·AI 리포트를 제공하는 서비스를 기획하고 개발했습니다.

데이터 수집과 저장. 기본 조회에서는 최근 7일 기록을 수집하고, 30일·90일 분석을 요청하면 과거 빈 날짜를 10일 단위로 보충합니다. 이미 저장한 정상 기록은 재사용해 중복 요청을 줄였습니다. 미공개 날짜, 아직 수집하지 않은 날짜, 일시적인 API 오류를 구분하고 오류나 빈 응답으로 기존 정상 기록을 덮어쓰지 않도록 처리했습니다.

분석과 예측. 경험치 증가량, 일평균, 레벨 진행률, 랭킹 변화와 기간 비교는 애플리케이션 로직에서 계산합니다. 기록이 부족하거나 관측 구간이 끊긴 경우 임의로 값을 보간하지 않으며, 다음 레벨 예상도 계산 가능한 변화가 충분할 때만 참고값으로 표시합니다. 성장 타임라인과 추이 그래프, 두 캐릭터의 동일 기간 비교도 구현했습니다.

AI와 운영. AI는 계산된 지표와 기록을 자연어로 설명하도록 역할을 분리했습니다. Gemini를 우선 사용하고 설정·오류 조건에 따라 OpenRouter를 대체 경로로 사용합니다. React 19 화면과 Flask API를 분리하고 PostgreSQL(배포)·SQLite(로컬) 저장 환경을 구성했으며, Python 테스트·JavaScript 테스트·React 빌드 검사를 GitHub Actions에 연결했습니다.

사용 결과. 배포 후 지인 10명 내외가 사용했고, 받은 피드백과 건의사항 중 서비스 방향에 맞는 내용을 일부 반영해 개선했습니다.

Python · Flask · React 19 · Vite · PostgreSQL · SQLite · Chart.js · NEXON Open API · Gemini · OpenRouter

SENTRATEAM CAPSTONE · 2026

서버에서 접근 권한을 판단하는 사내 자원 통제 시스템

3인 팀 캡스톤으로, 직원의 역할·소속·개인 권한에 따라 사내 자원 접근을 허용하거나 거부하는 시스템입니다. 조장은 Azure 서버·아키텍처·프론트엔드·챗봇을, 다른 팀원은 네트워크 가상망과 Packet Tracer 시연을 담당했고, 저는 Flask 서버 백엔드를 맡아 로그인 인증, 직원 데이터, 초대 가입, 계정 상태와 기간제 권한 처리를 구현했습니다.

계정과 인증. 비밀번호 해시 기반 로그인과 JWT 발급을 연결하고, 관리자가 사전 등록한 직원 명부를 기준으로 사원번호와 일회용 초대 코드를 검증하는 가입 흐름을 구현했습니다. 초대 코드 재사용을 막고, 비활성 계정은 로그인 및 보호된 API에 접근하지 못하도록 처리했습니다.

권한 생명주기. 접근이 거부된 자원에 대해 직원이 권한을 요청하고 운영자가 승인·반려하며, 승인된 권한은 지정된 기간 동안만 적용되도록 구성했습니다. 만료되거나 관리자가 회수하면 기존 정책으로 돌아가는지 주요 시나리오를 실행해 확인했습니다. 화면의 메뉴 표시만 신뢰하지 않고 서버가 요청마다 인증과 정책을 판단하도록 한 것이 핵심입니다.

협업과 범위. 담당 기능의 요구사항 정의, DB 스키마와 플로우차트를 작성하고 화면과 API의 요청·응답 규격을 맞췄습니다. 네트워크 가상망·Packet Tracer, Syslog/NetFlow 수집, Discord 알림과 프론트엔드 구현은 팀원의 담당 범위로 구분합니다.

개인 담당: Python · Flask · PyJWT · SQLite / 팀 화면 환경: React · TypeScript (프론트엔드 담당: 조장)
