# Continuing Device · 기록 집계 장치

BR-A의 기록 후보와 통계를 다시 생성하는 로컬 Python 프로그램입니다. AI가 내용을 자동으로 공개하지 않으며, 생성 결과를 확인하고 사이트에 반영할 내용은 직접 선택합니다.

## 구조

```text
device/
├── input/
│   ├── records.json
│   ├── ritual-days.json
│   └── ritual-summary.json
├── output/
│   ├── candidates.json
│   └── stats.json
└── src/
    ├── generate.py
    └── stats.py
```

## 입력 데이터

- records.json: 사이트에 공개할 대표 기록 후보. 현재 35건.
- ritual-days.json: 날짜별 상태를 보관한 상세 요약 자료. 개인 회고 원문이나 동료 관련 텍스트는 포함하지 않습니다.
- ritual-summary.json: 최신 자기소개서에서 확인한 전체 집계값. 사이트에 표시하는 전체 수치의 기준입니다.

### 최신 공개 집계

최신 자기소개서 기준으로 다음 수치를 사용합니다.

- 기록 기간: 2026-08-11 ~ 2026-11-12
- 기록한 날: 61일
- 마감 기록: 61일
- 진행 중 기록: 0일
- '실천했다': 57일
- '일부 실천했다': 4일

날짜별 세부 내역과 최신 집계값은 목적이 다릅니다. 모든 날짜별 원자료를 공개 저장소에 추가하지 않고도 확인된 최신 합계를 재현할 수 있도록 별도 요약 파일을 사용합니다. 전체 기록 수는 날짜별 요약의 과거 집계값으로 되돌아가지 않도록 ritual-summary.json을 우선합니다.

### 대표 기록 후보

대표 기록 후보 35건의 역량별 분포는 다음과 같습니다.

- 자기조절력: 14건
- 대인관계력: 13건
- 자기동기력: 8건

이 분포는 선별된 후보 35건에만 적용되며 전체 리추얼 기록 61일의 역량별 분포를 의미하지 않습니다.

## 실행 방법

저장소 루트에서 실행합니다.

```bash
python3 device/src/generate.py
python3 device/src/stats.py
```

생성 결과:
- device/output/candidates.json
- device/output/stats.json

동일한 입력 파일과 코드를 사용하면 같은 결과가 생성됩니다.

## 업데이트 원칙

1. 공개할 대표 기록 후보는 input/records.json에 선별해 추가합니다.
2. 전체 기록의 최신 집계가 바뀌면 확인된 합계만 input/ritual-summary.json에 반영합니다.
3. 날짜별 상태를 공개 가능한 형태로 보완할 때는 개인 회고 원문을 넣지 않고 input/ritual-days.json에 필요한 요약만 추가합니다.
4. Python 프로그램을 실행하고 결과를 확인합니다.
5. 사이트에 공개할 내용을 직접 선택해 반영합니다.

## 판단과 개인정보

- 프로그램은 후보와 통계를 계산할 뿐 사이트에 자동 게시하지 않습니다.
- 원문 회고와 타인의 개인정보는 공개 입력 파일에 넣지 않습니다.
- 집계 숫자는 최신 자기소개서와 대조해 확인한 뒤 업데이트합니다.
